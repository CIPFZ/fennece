本里程碑实现
- 持久化 `.fnx`（ADR-003/012）：分段 + 校验、原子写 + .bak、损坏重建、按卷续读或重建、周期保存与退出保存；
  `-reindex` `-nodb` `-db`。
- 服务模式（ADR-011）：fennec-service（windows-service），只读协议，管道 DACL，`-install-service`/`-uninstall-service`。
- 卷热插拔：新卷私有枚举后并入索引，返回的卷续读日志。
- 查询语言补全：其余 core 函数、集合函数、拼音/ascii/fuzzy 修饰符、日期/时长语法全集、用户宏、筛选器语义（详见 CHANGELOG）。
- UI：命令体系与可改键位、菜单栏、19 个基础列（选择/拖拽排序/宽度记忆）、多级排序、多选、Shell 右键菜单、拖出、
  剪贴板、IFileOperation 文件操作、筛选器栏/管理器/导入、书签、搜索历史与补全、搜索构建器、导出、`/key=value`
  行内命令、选项窗口（全部页面 + 键盘 + 高级）、主题切换、窗口几何记忆。

在 Windows 实测中发现并修复
1. 结果行收不到鼠标点击（标签默认可选中文本吞掉了点击）。
2. egui-winit 把 Ctrl+C/X/V 转成剪贴板事件，键位表收不到；剪贴板只有文件时 Ctrl+V 完全没有事件；Shift+Del 被当成剪切
   → 结果列表中按剪贴板事件分发，并用窗口子类化计数 Ctrl+V / Shift+Del。
3. 粘贴到源文件夹失败 → FOF_RENAMEONCOLLISION；永久删除弹两次确认 → 只保留 Fennec 的确认框。
4. 已删除条目仍计入选择；多键排序引入约 35% 排序回退 → 单键比较器单态化。
5. 正在运行的服务锁住 fennec-service.exe 导致构建失败 → 服务从 C:\Program Files\Fennec 安装。
