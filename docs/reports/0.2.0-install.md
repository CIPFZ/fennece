### 7. 观察与建议（未改代码）

1. 3.19：任何用户会话中 Fennec 在运行时卸载/升级，需要重启才能完成（Installer 无法关闭其他会话的进程；同会话时重启管理器可自动关闭）。HKLM `Run` 使每个登录用户都会启动 Fennec，多用户机器上很常见。建议在发行说明中写明"卸载/升级前先在所有会话退出 Fennec"；若要自动处理，可在 MSI 中加 `util:CloseApplication`（会结束其他用户的进程，需决定）。
2. 4.5：无模型时语义状态在首次查询前显示"就绪（0 块）"；状态栏长提示与语义状态文字重叠。
3. MSI 界面为 WiX 默认图片、仅英文，资源管理器菜单项 "Search Fennec"/"Explore in Fennec" 在中文系统上为英文；完成页无"启动 Fennec"。
4. 5.2：无服务的便携版每分钟记录两行 `cannot open arrived volume`。
5. 测试期间其他代理的窗口（rel05b 的 Fennec 与 PowerShell）在持有 gui_lock 时被带到前台；管理员桌面上有一个 XDesk 对话框（"检测到另一个 xdesk_server 正在运行…"，平台组件），未处理。
