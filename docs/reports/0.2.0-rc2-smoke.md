### 前两次运行（测试脚本的问题，与安装包无关）

1. **第 1 次**：从 GitHub CDN 下载标准 MSI 时连接中断（"从传输流收到意外的 EOF"），后面的检查都因为没装上而失败。已中止，脚本改为下载失败时重试，直到哈希一致。
2. **第 2 次**：3 项失败，都是检查方法错误，换了正确方法后第 3 次运行通过：
   - "便携数据在 `.\data`"按 `data\settings.toml` 判断：设置只有改动后才写，索引 5 min 才保存一次，而测试 200 s 就结束，所以这个文件不存在；实际 `data\` 下已有 `logs`、`index.excl`、`journal.tsv`。改为看日志里的数据目录。
   - "实验包链接 llama.cpp"用 `Select-String` 在 exe 中找 `llama_backend_init`：它按文本读二进制，找不到这个字符串；按字节搜索实际有 408 个 `llama_*` 字符串，标准包为 0。改为按字节搜索。
   - 另外，"每卷只记一次"原来在一行都没有时也算通过，现在要求至少 1 行。

证据：VM 上 `D:\rc2\smoke.log` 与 `D:\rc2\evidence\`（两个包各自的崩溃报告、IPC 列出的筛选器/书签、导出的 toml、便携版日志）。

### 正式版

`v0.2.0` 打在与 rc.2 相同的提交 `4f759a6` 上，Release 由 CI 从该 tag 重新构建。MSI 每次构建生成新的包代码，zip 内含时间戳，所以文件哈希与 rc.2 不同，以 Release 页面的 `SHA256SUMS.txt` 为准。
